# 2026-08-18 低温喷雾干燥机行业情报日报

## 执行摘要

- 🔵 **已验证事实：** 截至 **2026-08-18**，最新高相关产业信号来自 **2026-08-13 PolyPeptide H1 2026**、**2026-08-13 Cargill EpiCor postbiotic**、**2026-08-03 Codis 完成 Catalent Nottingham 喷雾干燥资产收购**、以及 **2026-07-20/23 Samsung Biologics 对 PolyPeptide 的并购与财报重申**。这组信号共同指向：`peptide CDMO`、`pharmaceutical spray drying`、`functional bioactive powders` 三条线都在加速。
- 🔵 **已验证事实：** PolyPeptide 于 **2026-08-13** 公布 **H1 2026 收入同比 +42%**，并把全年收入增长指引上调到 **25-30%**。这说明 GLP-1 / metabolic peptides 对上游肽 API 外包需求仍然强劲。
- 🔵 **已验证事实：** Codis 于 **2026-08-03** 完成对 Catalent Nottingham, UK 设施的收购，并明确对外表述为扩大 `Europe's Premier Spray Dry Network`。这意味着欧洲药用喷雾干燥 CDMO 产能仍在被资本集中。
- 🔴 **关键判断：** `35C inlet low-temperature spray dryer` 当前最强定位仍然不是“无条件替代 lyophilization”，而是 **冻干减载、前期配方筛选、连续化中试放大、热敏粉体开发加速器**。
- 🔴 **关键风险：** 对蛋白/多肽类，喷雾干燥能否成立，取决于 `residual moisture / water activity / reconstitution / aggregation / activity retention` 是否同时过关；已有研究明确提示 **亚优工况会导致重溶后高颗粒与聚集风险**。
- 🟢 **我方切入机会：** 最优客户顺序建议为 `GLP-1 / peptide CDMO` → `biologics / proteins` → `postbiotics / enzymes / probiotics` → `functional food / natural extracts / heat-sensitive materials`。

- 欧洲和北美喷雾干燥平台继续整合，客户会更倾向采购 **可验证、可转移、可放大的工艺包**，而不是单点设备。
- `GLP-1 Bridge` 带来的需求放大，对我方不是直接卖药机会，而是 **为上游肽类、口服固体、粉体中间体、无菌粉体路线提供工艺验证窗口**。

## 研发工艺匹配报告 (R&D & Process Alignment Report)

### 🔴 工艺定位

- `35C inlet low-temperature spray dryer` 的最佳研发定位是：**先证明它在某一类物料上可行，再决定是否进入放大或与冻干并行**。
- 对药用蛋白/多肽，不能只谈“低温”；必须闭环验证：`outlet temperature`、`residence time`、`residual moisture`、`water activity`、`particle size distribution`、`activity retention rate`、`protein aggregation`、`peptide chemical stability`、`reconstitution behavior`。
- 对益生菌/酶/天然提取物，不应泛化承诺“全部可替代冻干”，而应先做最小案例，明确活性保持与储存衰减曲线。

### 🔵 已验证事实

- Lund University **2026** 论文明确把 `low-temperature vacuum spray drying (VSD)` 定义为 **probiotic and live biotherapeutic product formulations** 的潜在干燥路径，并把 `bacterial viability`、`water activity`、`process development` 作为核心关键词。
- Springer 公开研究指出，喷雾干燥对治疗性蛋白是 `promising alternative drying method to lyophilization`，但同一研究也显示 **亚优工况下重溶后会出现高水平可见/亚可见颗粒**。这直接说明：替代路线有潜力，但窗口很窄。
- FDA 在 **2026-04-01** 的 GLP-1 compounding 政策更新中再次强调，`semaglutide injection products` 的短缺已在 **2025-02-21** 被判定 resolved，且制造能力可满足当前和预测需求；这说明未来竞争重点会逐步从“短缺套利”转向 **合规质量、供给效率与差异化制剂开发**。

### 🔴 当日研发判断

- 对 `GLP-1 / peptides`：最适合的切入动作是 **粉体中间体 feasibility study**，不要先宣传全面替代注射制剂的冻干路线。
- 对 `biologics / proteins`：必须把 `aggregation` 与 `reconstitution` 提升到和 `activity retention` 同级，否则会在放大后直接失效。
- 对 `postbiotics / functional bioactives`：这是近期最容易先落地的低温连续粉体场景，因为其稳定性要求通常比 live probiotic 更容易达标。
- 对 `probiotics`：应优先验证 `viability`、`aw`、`storage decay`，再决定是否商业放大。
- 对 `heat-sensitive materials / natural extracts`：重点不只是低温，而是 `oxidative stability + dispersibility + shelf stability`。

### 🟢 建议的最小验证案例

1. `Case A - GLP-1 / model peptide powder intermediate`
   目标：验证 `chemical stability + aw + residual moisture + reconstitution`。
2. `Case B - postbiotic / enzyme / natural extract`
   目标：验证 `activity retention + shelf stability + continuous production economics`。
3. 每个案例都保留一条 `lyophilization` 或常规喷干对照线，只比较五项核心数据：`周期`、`能耗`、`残余水分`、`活性`、`复溶/分散表现`。

## 市场与前景评估报告 (Market & Outlook Report)

### 🔵 已验证事实

- `peptide API manufacturing` 头部企业经营数据仍在加速，PolyPeptide 的 **+42% H1 增长** 是截至 **2026-08-18** 最强的直接市场读数之一。
- 喷雾干燥 CDMO 不是减速，而是在通过并购继续做大区域网络，Codis 的 Nottingham 收购就是直接证据。
- 支付端对 GLP-1 的实际放量机制已经启动，CMS 给出的时间窗口是 **2026-07-01 至 2027-12-31**，这会继续增强肽类产业链的容量预期。
- 功能性活性粉体侧，后生元仍在增强消费与品牌端存在感，说明连续粉体技术在食品/营养方向也有现实订单空间。

### 🔴 来源推断

- 未来 6 到 12 个月，最容易成交的不是“设备替代冻干”故事，而是 **验证服务包 + 中试数据包 + 放大方法学 + 能耗/周期对比包**。
- 若我方只强调 `35C`，容易被理解成概念卖点；若强调 **低热史、短周期、冻干减载、可转移验证**，对研发和采购都会更有说服力。
- 医药客户排序上，`CMC risk reduction`、`quality consistency`、`timeline acceleration` 通常优先于单纯 `energy saving`；而在功能食品与天然提取物领域，节能与连续化会更容易成为采购触发点。

### 🟢 结论性判断

- **最优切入口 1：** `GLP-1 / peptide CDMO`
- **最优切入口 2：** `biologics / proteins`
- **最优切入口 3：** `postbiotics / enzymes / probiotics`
- **最优切入口 4：** `functional food / natural extracts / heat-sensitive materials`
