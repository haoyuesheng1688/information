## 2. 研发工艺匹配报告 (R&D & Process Alignment Report)

### 🔴 酶活评价：检测可及性与真实失活要分开

**已验证事实：** 2026 年 8 月 21 日在线发表的 Bacillus tequilensis 蛋白酶研究比较包埋基质与喷雾/冻干，摘要显示配方浓度影响表观活性和粉体回收；机械破坏包埋后活性增加，提示部分低测值可能源于传质/可及性限制，而非全部酶失活。本次取得出版商摘要和日期，未做全文参数审计，不把它当作 35℃验证。[S5](https://journal.hep.com.cn/smab/EN/10.1007/s43393-026-00532-x)

**我方研发建议：** 增加“完整微胶囊直接测活”和“经验证的完全释放后测活”两条分析支路，设置配方空白、底物扩散/释放对照，避免将保护性包埋误判为失活，或把释放速度差异误报为低温优势。

### 🔴 最小可行验证：先做非无菌模型酶

以下为待执行方案，不是实验结果：

1. 选一种可稳定测定活性的非无菌模型酶；同一原料批次、相同配方、相同固含，比较冻干、常规喷雾、35℃进风候选工况。各路线先做可行性筛选，通过后至少三次独立批次重复。
2. 预先约定等效含水率与水活度终点；35℃路线若达不到终点，记录为该工况未通过，不以湿粉低温测活宣称成功。终点数值随物料与用途确定，不设跨品种通用阈值。
3. 完整记录 inlet/outlet temperature、入口露点、气量、进料速率、料温、压力、雾化参数、氧含量（如适用）、residence time 估计方法及分布。35℃进风与35℃出风严格区分。
4. 测 residual moisture、water activity、粒径分布 D10/D50/D90、复溶时间与不溶物、结构稳定性、活性保留率和总活性回收率；活性结果按干基并扣除载体稀释影响。
5. 将总活性回收率定义为“收集粉末总活性单位/投料总活性单位”，同时报告粉末质量回收率；不能只给 U/g 或只报最优批次。
6. 比较全周期时间及全系统能耗，包含除湿/再生、风机、压缩气、真空、冷却、二次干燥和清洗；同时报告 kWh/kg 蒸发水与 kWh/kg 合格粉。没有实测数据前不填节能百分比。
7. 进行初始、短期筛选及目标货架期稳定性评价；短期合格不等于货架期已证明。只有质量与经济性均过门槛，再推进中试放大。

### 🔴 分行业质量门槛

| 物料/应用 | 除共性指标外的小试重点 | 35℃路线的适用边界 |
|---|---|---|
| GLP-1、多肽 API | 活性、HPLC杂质/LC-MS、peptide chemical stability、复溶性、固态与残留溶剂 | 对具体分子逐一论证；不能由 API 扩产推断冻干可替代 |
| biologics/proteins | 活性、SEC聚集、protein aggregation、结构变化、复溶颗粒 | 雾化界面与脱水应力仍在；无菌收粉及灌装另行验证 |
| 酶制剂 | 比活性、总活性回收、释放后活性、结构稳定性 | 优先适合分析方法明确的非无菌筛选 |
| 益生菌 | CFU/g、总活菌回收、probiotic viability、复水损失及储藏存活 | 菌株与载体相关；残水低不自动等于存活率高 |
| 功能食品/天然提取物 | 标志物、氧化、风味、复溶、载体比例及最终食品感官 | 活性和配方稀释要分开核算；不可把体外抗氧化等同人体功效 |
| 纳米材料/蛋白复合颗粒 | 干粉粒径与复分散粒径分别测，团聚、表面性质、功能保持 | 研究所述纳米分散体不等于纳米喷雾液滴或干粉D50 |
| 疫苗/mRNA | 效价、结构/完整性、递送体系、无菌及稳定性 | 本次无新增35℃直接证据，作为长期探索而非近期销售承诺 |
